# 四方連續圖生成

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

將平面圖處理成可四方連續拼接的單元圖，並以 2×2 預覽驗證接縫。接縫處不做模糊，多餘前景以硬切改為背景色。

可選串接內建 `kuotu` 做平鋪擴展、裁切、白邊／黑邊，並輸出 TIFF／PNG／JPEG。

## 功能

- 單張／資料夾同一套流程：載入 → 預覽 → 按按鈕決定步驟
- 步驟 1：四方連續（單元圖 + 2×2 預覽／匯出）
- 步驟 2：擴圖裁切加邊（僅此步驟使用擴展／裁切／邊框參數）
- 批次：勾選要跑的步驟後，對資料夾全部套用
- 滿鋪紋理自動相位／週期對齊；疏點綴花布可清邊補花
- 跑無縫之前先分流：成品外框與產品封面圖直接跳過、不寫輸出檔

## 環境需求

- Python 3.10+
- Windows / macOS / Linux

## 使用流程

### 共通原則

**載入不會出圖。** 先選輸入／輸出資料夾（或開啟單張），調參數與預覽後，再按「開始批次處理」或單張匯出擴圖。

### 單張預覽

1. **開啟單張圖片…**，或選好 **輸入資料夾** 後用上一張／下一張瀏覽
2. 確認背景色、邊緣帶、色差閾值
3. **處理目前圖片** → 若是封面／有框會顯示跳過原因且不產生單元圖；其餘切換「單元圖／2×2 預覽」檢查接縫（僅畫面預覽，不另存中間檔）
4. 若要單張成品：**匯出目前圖片的擴圖…**

### 資料夾批次

1. 選 **輸入資料夾**、**輸出資料夾**
2. 需要時勾選 **SKU 批次**（子資料夾名「-」前為 SKU）並選 Excel
3. 調好擴圖參數後按 **開始批次處理** → 封面／有框會跳過不寫檔，其餘只輸出最終擴圖（保留子資料夾結構）

SKU 模式的裁切尺寸由 Excel 尺碼決定；一般模式用右側「裁切 cm」。

## 參數說明

| 參數 | 用途 | 說明 |
|------|------|------|
| 背景色／邊緣帶／閾值 | 預覽與批次 | 生成四方連續單元圖用 |
| 擴展／裁切／白黑邊 cm、DPI、格式 | 擴圖 | 「匯出目前圖片的擴圖」或「開始批次處理」時生效 |
| 邊緣帶 = 0 | 預覽與批次 | 不清邊補花；滿鋪仍可週期對齊 |

## 演算法摘要

流程分成四段：分流、產生候選、驗收、擇優。**只有能證明自己無縫的候選才有資格出線**，
沒有「試不出來就退回原圖」這條退路。封面圖與成品外框在進核心之前就攔下。

### 0. 分流（`app/triage.py`）

判斷看畫面內容，不看檔名。四方連續花布空間平穩（任一象限顏色分佈都該差不多）；
產品封面圖（尺寸表、行銷字、半張空白）不是。非平穩還不夠——水彩暈染、拼布格
同樣非平穩，但那就是設計——所以要再加拼貼／半張空白證據才跳過。寧可放過不可錯殺。

- **成品外框**：四邊同色近定值帶（黑／白／灰／品牌色），或 kuotu 外黑內白雙框
- **產品封面圖**：非平穩 **且**（半張空白、或高對比行銷文字排版）
- 判定為 `framed` / `not_pattern` 的圖**不寫任何輸出檔**，只在報告列出原因

### 1. 產生候選（`app/processor.py`）

保真度最高的無損來源優先：

- **原稿本身**：多數印花稿件本來就是四方連續，量到無縫就直接採用
- **週期裁切**：抓到真實重複週期就裁一個單元出來，像素零改動。密格紋／直條紋
  會優先裁 1～3 格小單元（大裁切容易累積相位誤差）
- **點綴晶格**：規則排列的星／花／愛心，以質心構造裁切
- **清邊補花**：疏點綴專用，清掉碰邊殘花再環繞補回密度

### 2. 保證無縫（`app/seamless_core.py`）

候選若還有縫，用兩個**由構造保證**結果可拼接的算子處理，不是碰運氣：

- **最小誤差切**：在邊緣重疊帶裡找一條最小誤差切線縫合首尾。像素全部直接
  來自原稿，色值零改動；代價是單元略為縮小、接縫附近有少量內容重複。
- **梯度域週期化**：Moisan periodic + smooth 分解，把不連續量表示成一個解
  Poisson 方程的極平滑場並減掉。細節完全不糊，代價是疊上一層平滑的明暗修正。

順序要緊：單獨用週期化去修一條 80 階的大縫，修正場本身就會變成一大片色偏
（實測平均 18/255）；先切再週期化，色偏平均只剩 0.2。

### 3. 驗收與擇優（`app/select.py`、`app/quality.py`）

- **接縫超出量**：把單元當環形掃描每一條線，量「該線差減掉該處應有的線差」。
  半幅搬家只是把縫移到中央，在這個尺度下無所遁形。
- **還原度**：把單元平鋪回原尺寸與原圖對齊比對。抓到真週期的裁切即使只有原圖
  百分之一大也完全還原；假週期把花距拉成兩倍就會現形。
- **色偏**：逐像素平均、低頻色塊、截斷比例三道分開量，通道均值擋不住
  「一半變亮一半變暗」這種互相抵銷的大偏移。

### 色彩

- CMYK 印刷稿**進出都是 CMYK**，內嵌 ICC profile 一路帶到最終檔
- 判斷在 sRGB 做，像素搬移直接作用在原生通道；CMYK→sRGB→CMYK 來回轉換實測
  會造成平均 4–8 階、最大 37 階的視覺色偏，比接縫修復本身大一個數量級
- **背景色**：自動從邊緣 + 平坦區識別

## 測試

```bash
python tests/test_triage.py      # 分流校準：封面召回、花布不得誤殺
python tests/sweep_all.py        # 全量掃描，產生分區 2×2 審查牆 HTML
python tests/regression_suite.py # 回歸集，以客觀指標守住已修好的圖
```

`tests/sweep_all.py` 依內容雜湊去重，審查牆按 FAIL／可疑／跳過-封面／跳過-有框／PASS 分區，點縮圖可看 1:1 接縫特寫。

## 專案結構

```
si-fang-lian-xu-tu-sheng-cheng/
  main.py
  啟動GUI.bat
  requirements.txt
  kuotu/
    image_pipeline.py   # 平鋪擴展／裁切／加邊
  app/
    gui.py
    triage.py           # 跑無縫前分流：有框／封面圖跳過
    processor.py        # 候選產生器與 2×2 預覽
    seamless_core.py    # 保證無縫的算子：最小誤差切、梯度域週期化
    select.py           # 候選展開、無縫閘門、保真度擇優
    quality.py          # 接縫／色偏／還原度指標
    color_io.py         # 色彩空間進出，ICC 全程保留
    color_utils.py
    discrete_lattice.py
    pipeline.py         # 串接 kuotu 擴圖
    paths.py
  tests/
    sweep_all.py        # 全量掃描 + 分區 2×2 審查牆
    test_triage.py      # 分流校準
    triage_labels.json
    regression_suite.py
    regression_baseline.json
```
