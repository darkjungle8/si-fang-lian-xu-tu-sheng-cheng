# 四方連續圖生成

將平面圖處理成可四方連續拼接的單元圖，並以 2×2 預覽驗證接縫。接縫處不做模糊，多餘前景以硬切改為背景色。

可選串接內建 `kuotu` 做平鋪擴展、裁切、白邊／黑邊，並輸出 TIFF。

## 功能

- 單張處理：開啟圖片 → 調整參數 → 產出單元圖與 2×2 預覽
- 批次生成：對資料夾批量輸出 `_unit.png` / `_2x2.png`
- 完整流水線：生成單元圖後自動擴圖、裁切、加邊並匯出 TIFF
- 滿鋪紋理自動相位／週期對齊；疏點綴花布可清邊補花

## 環境需求

- Python 3.10+
- Windows / macOS / Linux

## 安裝

```bash
git clone https://github.com/darkjungle8/四方连续图生成.git
cd 四方连续图生成
pip install -r requirements.txt
```

## 啟動

```bash
python main.py
```

Windows 也可雙擊 `啟動GUI.bat`。

## 使用流程

### 單張

1. **開啟圖片**
2. 確認背景色、邊緣帶、色差閾值
3. 按 **處理**，查看單元圖／2×2
4. **匯出單元圖**、**匯出 2×2**，或 **匯出擴圖 TIFF…**

### 批次（僅生成）

**批次處理資料夾** → `output/{檔名}_unit.png`、`_2x2.png`

### 完整流水線（生成 → 擴圖 TIFF）

1. 右側設定擴展／裁切／白黑邊 cm、DPI
2. 按 **完整流水線（生成→擴圖 TIFF）…**

輸出 `pipeline_out/`：

| 子目錄 | 內容 |
|--------|------|
| `units/` | 單元圖 |
| `previews/` | 2×2 預覽 |
| `tiff/` | 擴圖裁切加邊後的 TIFF |

## 參數說明

| 參數 | 說明 |
|------|------|
| 背景色 | 預設自動從邊緣識別；可關閉後手動吸色／填色碼 |
| 邊緣帶寬度 | 碰到此範圍的殘缺圖案會被清除後再補（建議 0.5%～3%） |
| 色差閾值 | 與背景的歐氏距離；超過視為前景圖案（預設 40） |
| 擴展／裁切 cm | kuotu 平鋪畫布與裁切尺寸 |
| 白邊／黑邊 cm | 裁切後外框 |

## 演算法摘要

- **滿鋪／密鋪**（條紋、魚鱗、幾何紋等）：自動做相位對齊（循環平移找最佳原點），並試週期裁切；取接縫更好的結果
- **疏點綴花布**（底色明顯、花朵獨立）：加大邊緣帶 → 清碰邊殘花 → 稀疏環繞補花
- **背景色**：自動從邊緣 + 平坦區識別
- **邊緣帶 = 0**：不走清邊補花；滿鋪仍會自動相位／週期對齊
