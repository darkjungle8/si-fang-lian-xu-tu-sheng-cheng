# 四方連續圖生成

將平面圖處理成可四方連續拼接的單元圖，並以 2×2 預覽驗證接縫。接縫處不做模糊，多餘前景以硬切改為背景色。

可選串接內建 `kuotu` 做平鋪擴展、裁切、白邊／黑邊，並輸出 TIFF／PNG／JPEG。

## 功能

- 單張／資料夾同一套流程：載入 → 預覽 → 按按鈕決定步驟
- 步驟 1：四方連續（單元圖 + 2×2 預覽／匯出）
- 步驟 2：擴圖裁切加邊（僅此步驟使用擴展／裁切／邊框參數）
- 批次：勾選要跑的步驟後，對資料夾全部套用
- 滿鋪紋理自動相位／週期對齊；疏點綴花布可清邊補花

## 環境需求

- Python 3.10+
- Windows / macOS / Linux

## 使用流程

### 共通原則

**載入不會出圖。** 開啟圖片或載入資料夾後，先預覽、調參數，再按步驟按鈕。

### 單張

1. **開啟圖片…**
2. 確認背景色、邊緣帶、色差閾值
3. **步驟 1 · 處理目前圖片** → 切換「單元圖／2×2 預覽」檢查接縫
4. 需要時再 **匯出單元圖…**／**匯出 2×2…**
5. 若要成品：**步驟 2 · 匯出目前圖片的擴圖…**（使用下方擴展／裁切／邊框 cm）

### 資料夾（與單張同一邏輯）

1. **載入資料夾…** → 只載入預覽，可用 **上一張／下一張** 瀏覽
2. 對目前這張按 **處理目前圖片**，確認效果
3. 若只要成品：按 **對資料夾批次擴圖（只出最終檔）…** → 只輸出 `pipeline_out/`（步驟 1 在記憶體執行，不落盤）
4. 若需要中間檔：在「批次 · 自訂輸出」勾選單元圖／2×2 後，按 **對資料夾全部套用勾選步驟…**

輸出：

| 操作 | 目錄 |
|------|------|
| 批次擴圖 | `pipeline_out/`（只有最終檔） |
| 另勾單元圖／2×2 | 額外輸出到 `output/` |

SKU 模式（子資料夾＝SKU、尺碼讀 Excel）僅影響步驟 2 的裁切尺寸；在步驟 2 區勾選後再跑批次。

## 參數說明

| 參數 | 所屬步驟 | 說明 |
|------|----------|------|
| 背景色／邊緣帶／閾值 | 步驟 1 | 生成單元圖用；步驟 2 不改這些 |
| 擴展／裁切／白黑邊 cm、DPI、格式 | 步驟 2 | 只在「匯出擴圖」或批次勾選步驟 2 時生效 |
| 邊緣帶 = 0 | 步驟 1 | 不清邊補花；滿鋪仍可週期對齊 |

## 演算法摘要

- **滿鋪／密鋪**（條紋、魚鱗、幾何紋等）：自動做相位對齊，並試週期裁切
- **疏點綴花布**（底色明顯、花朵獨立）：加大邊緣帶 → 清碰邊殘花 → 稀疏環繞補花
- **背景色**：自動從邊緣 + 平坦區識別
