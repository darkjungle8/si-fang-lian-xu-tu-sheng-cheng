# 四方連續圖生成

將平面圖處理成可四方連續拼接的單元圖，並以 2×2 預覽驗證接縫。接縫處不做模糊，多餘前景以硬切改為背景色。

可選串接內建 `kuotu` 做平鋪擴展、裁切、白邊／黑邊，並輸出 TIFF／PNG／JPEG。

## 功能

- 單張／資料夾同一套流程：載入 → 預覽 → 按按鈕決定步驟
- 步驟 1：四方連續（單元圖 + 2×2 預覽／匯出）
- 步驟 2：擴圖裁切加邊（僅此步驟使用擴展／裁切／邊框參數）
- 批次：勾選要跑的步驟後，對資料夾全部套用
- 滿鋪紋理自動相位／週期對齊；疏點綴花布可清邊補花

## 使用流程

### 共通原則

**載入不會出圖。** 先選輸入／輸出資料夾（或開啟單張），調參數與預覽後，再按「開始批次處理」或單張匯出擴圖。

### 單張預覽

1. **開啟單張圖片…**，或選好 **輸入資料夾** 後用上一張／下一張瀏覽
2. 確認背景色、邊緣帶、色差閾值
3. **處理目前圖片** → 切換「單元圖／2×2 預覽」檢查接縫（僅畫面預覽，不另存中間檔）
4. 若要單張成品：**匯出目前圖片的擴圖…**

### 資料夾批次

1. 選 **輸入資料夾**、**輸出資料夾**
2. 需要時勾選 **SKU 批次**（子資料夾名「-」前為 SKU）並選 Excel
3. 調好擴圖參數後按 **開始批次處理** → 只輸出最終擴圖（保留子資料夾結構）

SKU 模式的裁切尺寸由 Excel 尺碼決定；一般模式用右側「裁切 cm」。

## 參數說明

| 參數 | 用途 | 說明 |
|------|------|------|
| 背景色／邊緣帶／閾值 | 預覽與批次 | 生成四方連續單元圖用 |
| 擴展／裁切／白黑邊 cm、DPI、格式 | 擴圖 | 「匯出目前圖片的擴圖」或「開始批次處理」時生效 |
| 邊緣帶 = 0 | 預覽與批次 | 不清邊補花；滿鋪仍可週期對齊 |

## 演算法摘要

- **滿鋪／密鋪**（條紋、魚鱗、幾何紋等）：自動做相位對齊，並試週期裁切
- **疏點綴花布**（底色明顯、花朵獨立）：加大邊緣帶 → 清碰邊殘花 → 稀疏環繞補花
- **背景色**：自動從邊緣 + 平坦區識別
